# Dashboard screenshot checklist

Capture the single responsive dashboard page at 360px, tablet width, and
desktop width with:

- the repository selector and both `7d` and `30d` window states;
- loading skeletons, empty repository state, request error/retry, and stale
  data banner;
- populated metric cards with a null metric rendered as `No data`;
- deployment chart with a zero-deployment day;
- the red open-incident banner showing a live age;
- recent runs and incidents with keyboard focus visible;
- the token prompt and the unauthorized response path.

Do not include dashboard tokens, webhook URLs, payloads, or other credentials in
screenshots or captured fixture data.
